# 인덱스(index)
- 추가적인 쓰기 작업과 저장 공간을 활용하여 데이터베이스 테이블의 검색 속도를 향상시키기 위한 자료구조(색인)
- 데이터와 데이터 위치를 포함한 자료구조를 생성해 빠르게 조회가 가능하다는 장점
- 검색 성능을 유지하기 위해 데이터의 INSERT, DELETE, UPDATE시 인덱스 업데이트 필요
  1. INSERT: 새로운 데이터에 대한 인덱스를 추가
  2. DELETE: 삭제하는 데이터의 인덱스를 사용하지 않는다는 작업을 진행
  3. UPDATE: 기존의 인덱스를 사용하지 않음 처리하고, 갱신된 데이터에 대해 인덱스를 추가

### 단점
- 인덱스에 10% DB 저장공간 필요
- 추가적인 인덱스 관리 필요
- 잘못 사용시 성능 저하
